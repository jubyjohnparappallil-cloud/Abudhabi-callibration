# Backlink Tracker — Abu Dhabi Calibration

A backlink is a link from another website to ours. Google treats quality
backlinks as "votes of trust" that improve rankings. Track them here.

## What makes a GOOD backlink
- From a relevant, trustworthy website
- Uses natural anchor text (e.g. "calibration services in Abu Dhabi")
- "dofollow" (passes SEO value) — some are "nofollow" (still useful for traffic)

## Monthly Targets
- Month 1: Set up all directory + social profile backlinks (6–8 links)
- Month 2: 2–3 industry/partner backlinks
- Month 3 onward: 1–2 quality editorial backlinks per month (guest posts)

## Notes
- Quality over quantity: a few strong, relevant backlinks beat many spammy ones.
- Avoid buying cheap/spam links — Google can penalize these.
